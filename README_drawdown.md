# 每日收盘价与累计回撤监控

- 主调度：北京时间 18:30（UTC 10:30）。GitHub Actions 补偿检查：北京时间 21:17（UTC 13:17）和次日 07:17（UTC 23:17），不需要外部服务器。
- 业务规则保持不变：每次以计划执行日判断“次日 A 股或美股是否开市”，只有次日任一市场开市，计划日才有资格发布日报；手动触发可用于预览或补偿。
- GitHub schedule 可能迟到或丢失且不提供原计划触发时间。根据当前已到期的最后一个北京时间 18:30 时段，结合 Issue #1 中的 valuation-report 日期标记找出尚未发布的有效计划日，按时间顺序补处理（每次最多 5 天，最多向前查 45 天）。多次运行使用报告日期和 4% 跌幅事件 ID 去重。
- 手动 workflow_dispatch 如无欠账，也会重算最后已到期的计划日：publish=false 只预览；publish=true 提交数据但已发布的报告不会重复评论。
- 历史回放时，收盘价截止时间固定为该计划日北京时间 18:30，估值采集的 as-of-date 同样固定为计划日。没有新数据的指数应显示数据缺失或过期，不可将缺失当作零涨跌。
- 价格独立存储在 data/daily_prices.csv；data/drawdown_state.json 记录价格峰值、最新处理收盘日期和待发布事件。达到 4% 跌幅时记录事件并以触发日收盘价重置周期。
- GitHub Actions 的定时触发仍不保证准点；如果所有 cron 都被丢弃，只有后续真正启动的执行才能补偿。

运行测试：PYTHONPATH=src python -m unittest discover -s tests -v
