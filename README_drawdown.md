# 每日收盘价与累计回撤监控

- 定时任务：北京时间17:30（cron 使用 UTC 09:30），每天检查次日 A 股或美股是否开市；任一开市才发布日报。
- 手动执行默认为预览，不发布正式 Issue 评论，也不提交数据；勾选 publish 才正式发布。
- 价格数据每日独立存储在 data/daily_prices.csv；data/drawdown_state.json 记录价格峰值、最新已处理收盘日期和待发布事件。
- 价格来源使用公开日K收盘接口，使用真实交易所日历确认已结束的交易日；行情接口不通或缺少新数据时明确标记。
- 第一次启用各指数时以最近有效收盘价初始化，不回溯产生历史4%警报。
- 同周期内创出新高，则上调峰值；从峰值累计回撤达到或超过4%时记录事件，并从触发收盘价开始新周期。
- 同一交易日的冲突价格不会覆盖已有结果。估值使用原有每周历史，价格采用独立每日历史，不相互替代。
- 当 Issue 发布失败时，事件已保存于仓库；下次运行会重试。评论包含唯一报告日期和事件 ID 标记，可识别重复执行。
- 注意：GitHub Actions 的定时任务可能延迟触发，无法保证17:30整送达。
- 所有公开点位接口（包括价值100、中证红利和标普500）仍需通过实际 Actions 运行检验，不得将缺失数据推断成0%涨跌。

本地测试：`PYTHONPATH=src python -m unittest discover -s tests -v`
